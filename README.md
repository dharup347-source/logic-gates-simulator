# Logic Gates Simulator

A simple beginner-friendly Python project that simulates basic digital logic gates.

Perfect starting project for **Electronics & VLSI** students to understand how logic gates work.

## Supported Gates

| Gate  | Description                    |
|-------|--------------------------------|
| AND   | Output is 1 only if both inputs are 1 |
| OR    | Output is 1 if at least one input is 1 |
| NOT   | Inverts the input              |
| NAND  | Opposite of AND                |
| NOR   | Opposite of OR                 |
| XOR   | Output is 1 if inputs are different |
| XNOR  | Output is 1 if inputs are same |

## How to Run

```bash
python logic_gates.py
```

Then follow the on-screen menu.

## Example

```
Enter gate type (AND/OR/NOT/NAND/NOR/XOR/XNOR): AND
Enter first input (0 or 1): 1
Enter second input (0 or 1): 0
Result: 0
```

## What you will learn

- How basic logic gates work
- Writing clean Python functions
- Taking user input and validating it
- Building a simple interactive program
